# Student Management System

A simple and user-friendly **Student Management System** developed using **HTML, CSS, and JavaScript**.

This project allows users to manage student records through basic **CRUD operations** — Create, Read, Update, and Delete.

## 🚀 Live Demo

[Student Management System](https://sunithaevanjalin-coder.github.io/Student-management-system/)

## 📌 Project Overview

The Student Management System is a web-based application designed to make student record management simple and efficient.

Users can add student details, view existing records, edit student information, delete records, and search for students.

## ✨ Features

* ➕ Add new student records
* 👀 View student records
* ✏️ Update student details
* 🗑️ Delete student records
* 🔍 Search students by name or register number
* ✅ Form validation
* 📧 Email validation
* ⚠️ Duplicate register number validation
* 💾 Store student data using browser Local Storage
* 📱 Responsive user interface

## 🛠️ Technologies Used

### Frontend

* HTML5
* CSS3
* JavaScript

### Storage

* Browser Local Storage

## 📋 Student Details

The application manages the following student information:

* Student Name
* Register Number
* Email
* Department
* Year

## 🔄 CRUD Operations

| Operation  | Description                   |
| ---------- | ----------------------------- |
| **Create** | Add a new student             |
| **Read**   | Display student records       |
| **Update** | Edit existing student details |
| **Delete** | Remove a student record       |

Student records are stored in the browser using **Local Storage**.
